# Megtalált írások

Statikus blog és irodalmi weboldal,  
Eleventy (11ty) alapokon, egyedi layouttal és tipográfiával.

Az oldal célja kettős:
- személyes írások (novellák, gondolatok) publikálása
- webfejlesztői portfólió bővítése egy valós, működő projekttel

🌐 Élő oldal:  
https://tamas505.github.io/megtalaltirasok/

---

## Projekt célja

Ez a projekt egy **saját tervezésű, statikus blogmotor**, amely:

- többoldalas felépítést használ
- dinamikus tartalmat generál build időben
- GitHub Pages alatt, almappában fut
- nem tartalmaz backendet vagy adatbázist

A hangsúly:
- letisztult UI
- olvasható tipográfia
- karbantartható struktúra

---

## Funkciók

- 📄 Markdown alapú bejegyzések
- 🗂 Automatikus post collection (dátum szerinti rendezéssel)
- 🆕 „Legfrissebb írások” lista
- 📚 Régebbi írások oldal
- 🧭 Háromhasábos layout (navigáció / tartalom / kiegészítők)
- 🎨 Egyedi CSS (grid, responsive, tipográfia)
- 🖼 Egységesen kezelt képek a posztokban
- 🌍 GitHub Pages kompatibilis útvonalkezelés (`pathPrefix`)

---

## Technológiai stack

- **Static Site Generator:** Eleventy (11ty)
- **Template engine:** Nunjucks
- **Tartalom:** Markdown
- **Stílus:** natív CSS (Grid, Flexbox)
- **Build:** Node.js
- **Publikálás:** GitHub Pages
